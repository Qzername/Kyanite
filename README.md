# Kyanite 💎

A simple, versatile work management tool designed for personal use, featuring multiplatform support and seamless data synchronization.

> **Note:** The project is currently in the early stages of development.

- 📊 Kanban
- 📝 Note
- ⏰ Reminder
- ✅ ToDo List

## 💾 Supported Data Storage

- 📂 Local Database
- ☁️ Google Drive
