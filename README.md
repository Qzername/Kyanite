# Whiteboard

The most customizable work management tool - at least that's goal is to be one, because for now it is a work in progress. 

When creating the app, I had (and still have) three goals in mind:
- Easy to create new components 
- Costless to run for the client
- Available on at least mobile and desktop

Currently, to store data between devices the app connects to your Google Drive. It requires a little bit of configuration, but in my experience it is worth it.
