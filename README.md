# Kyanite 

A simple, versatile work management tool designed for personal use, featuring multiplatform support and seamless data synchronization.

> **Note:** This project is currently in the early stages of development.

## Features (v0.1.0)

- 📝 Notes (Markdown supported)
- 📊 Kanban Board
- ✅ To-Do List

## Data Synchronization

One of the core goals of the app is to provide easy-to-use data synchronization. Currently supported storage options are:
- **Local Database**
- **Google Drive** - The database is uploaded to Google Drive on each sync.
- **Kyanite API** *(Coming soon - v0.3?)*
